# GitHub Desktop: first upload (no command line required)

1. In GitHub, create a **new EMPTY repository** named `onyx-wrestlefest-game` under `leonzeigler`.
   Do not add a generated README or license at creation time.
2. Extract this ZIP to a new local folder. Keep `index.html` and `assets` in the folder root.
3. Open GitHub Desktop -> File -> Add Local Repository -> Choose that folder.
4. If GitHub Desktop says it isn't a repository, choose **Create a repository here**.
5. Commit all files, then **Publish repository** to GitHub. You can choose private or public.
6. Check the repository file list for `index.html`, `icon.webp`, `assets/`, and `README.md`.

Keep `onyx-wrestlefest-netplay` for your other AI's multiplayer server; don't upload the older bundled server from previous project ZIPs into it.

When published, send ChatGPT the new repository URL.
